# Cafe Promotional Poster

## Overview
This project is a modern café promotional poster designed using Pixso. The design highlights featured beverages, promotional offers, and essential café information with a clean and visually appealing layout.

## Tool Used
- Pixso

## Project Type
- Promotional Poster Design

## Features
- Modern café poster layout
- Promotional offer section
- Typography and visual hierarchy
- Attractive product presentation
- Call-to-action design

## Purpose
This project was created to practice graphic design principles, including layout composition, typography, color balance, and promotional design.

## Note
This is a concept design created for learning and portfolio purposes.
